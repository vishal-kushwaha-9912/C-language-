# C++ Complete Learning Guide

* Introduction to C++
* Input and Output
* Variables and Data Types
* Operators

* `if`, `if-else`, nested conditions
* `switch` statements

  * `for` loop
  * `while` loop
  * `do-while` loop

### Functions

* Function creation
* Parameters and arguments
* Return values
* Function overloading
* Recursion
* Pass by value and reference

### Arrays and Strings

* User input with `getline()`

### Problem Solving

* Beginner practice programs
* Tea shop examples ☕

## ▶️ How to Run the Code

1. Install a C++ compiler (MinGW/GCC)
2. Open the project in VS Code
3. Compile the file:

```bash
g++ filename.cpp -o output
```

4. Run the program:

```bash
./output
```
